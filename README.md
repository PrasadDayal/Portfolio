# 💼 Portfolio | Software Developer

A modern, responsive portfolio website built with **React**, **TypeScript**, and **Tailwind CSS**.  
It features smooth animations using **Framer Motion** and a clean, dark-themed UI.

---

## 🚀 Features

- **Responsive Design:** Optimized for all screen sizes (Desktop, Tablet, Mobile)
- **Interactive UI:** Custom cursor, glassmorphism effects, and scroll animations
- **Projects Showcase:** Project cards with GitHub & live demo links
- **Experience Timeline:** Visual representation of education & work
- **Contact Form:** Functional and styled contact section
- **Tech Stack Display:** Java, Spring Boot, React, etc.

---

## 🛠️ Tech Stack

- **Frontend:** React.js, TypeScript, Tailwind CSS, Framer Motion  
- **Icons:** Lucide React  
- **Build Tool:** Vite  
- **Deployment:** Vercel / Netlify / GitHub Pages  

---

## 🔧 Installation & Setup

### 1. Clone the repository
```bash
git clone https://github.com/your-username/your-repo-name.git
```
### 2. Install dependencies
```bash
npm install
```
### 3. Run development server
```bash
npm run dev
```
### 4. Build for production
```bash
npm run build
```
